# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use the repository's **Security** tab and select **Report a vulnerability** to send a private report to the maintainers. Include affected versions, impact, and reproducible steps when possible. Do not include real customer payloads, credentials, or personal data.

The project is an early pilot product. There is no published security response SLA or supported production release yet. Do not send sensitive production data until an explicit pilot agreement and deployment review are in place.
